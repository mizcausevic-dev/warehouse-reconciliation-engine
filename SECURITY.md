# Security Policy

## Supported Use

This repository is a portfolio project that demonstrates reconciliation and warehouse trust patterns. It should not be treated as a production finance control without additional environment-specific hardening, validation, and security review.

## Reporting a Vulnerability

If you discover a vulnerability in this repository, please report it privately through GitHub security reporting or by contacting the maintainer through the channels listed on [kineticgain.com](https://kineticgain.com/).

Please include:

- affected file or component
- reproduction steps
- expected impact
- suggested remediation if available
